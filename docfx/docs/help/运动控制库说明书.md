# 运动控制节点库说明

## 1，modbus读节点

    （1）描述：modbus读节点，用于从modbus设备读取数据。可以选择读取的数据类型：输入、输出、寄存器、线圈。
    （2）操作：双击modbus读节点，弹出节点配置面板：
        1.）选择modbus设备（IP地址和端口）
        2.）选择读取的站号
        3.）选择读取的起始地址
        4.)选择读取的个数，不同的个数节点会生成对应数量的引脚
        5.)选择读取类型：线圈、离散输入、保持寄存器、输入寄存器

## 2,modbus写节点

    （1）描述：modbus写节点是modbus协议写入节点.
    （2）操作：双击modbus写节点，弹出节点配置面板：
        1.）选择modbus设备（IP地址和端口）
        2.）选择写入设备的站号
        3.）选择写入的起始地址
        4.)选择写入的个数，不同的个数节点会生成对应数量的引脚
        5.)选择写入类型：线圈、寄存器

## 3，modbus电机节点

    （1）描述：modbus电机节点，用于控制《外圆》modbusIO卡的电机功能。
    （2）操作：在接好modbus设备后，双击modbus电机节点，弹出节点配置面板：
        1.）选择modbus设备（IP地址和端口）
        2.）选择modbusIO卡的站号

## 4，延时节点

    （1）描述：延时节点，用于延时指定时间后执行下一步
    （2）参数：正整数(单位：毫秒)

## 5，边缘触发节点

    （1）描述：边缘触发节点，用于触发一次边缘触发事件执行下一步。当接收到上升沿信号或者下降沿信号时，执行下一步。
    （2）参数：无。可通过配置来指定触发信号的电平。
