# 图像处理节点库

    描述：图像处理节点库，存放图像处理节点。包含3个子目录：前处理、工具和挂载在本目录下的图像检测算子。

## 一、工具文件夹

    工具文件下下存放辅助视觉处理的工具，比如加载图片，循环遍历文件夹

### 1，网口相机节点

    （1）描述：无输入。输出为图片（类型：Mat）需在下拉框中指定Gige相机设备，可配置为触发模式或者持续接受模式
    （2）输入：无
    （3）输出：（图像）Mat

### 2，读取图片节点

    （1）描述：无输入。输出为图片（类型：Mat）
    （2）操作：单击该节点，右下侧的节点属性栏里的高级选项组合里出现可配置项，点击选择按钮，弹出文件选择框，选择图片。

### 3，文件供应器节点

    （1）描述：无输入。遍历输出该指定文件夹下面的所有图片，每次执行输出一张图片。
    （2）操作：单击该节点，右下侧的节点属性栏里高级选项组合里出现可配置项，点击选择按钮，弹出文件选择框，选择文件夹。

### 4，创建ROI节点

    （1）描述：根据输入的图片在其上创建ROI,。
    （2）操作：
    双击该节点，弹出ROI绘制面板，输入的图片会显示在画布上。
    左键点击开始绘制，再次点击结束绘制。
    左键单击可以选中绘制的ROI,ROI被选中后，会在4个角点出现可拖拽圆点，鼠标左键点击拖拽圆点可以进一步调整ROI的形状和位置。左键拖拽ROI内部可以移动ROI。
    选中后按下del键可以删除ROI。
    邮件拖拽会拖拽画布，滚轮可以缩放画布
    （3）参数：ROI节点的 位置，形状，偏置可以继承节点图其它节点的数据，实现ROI继承，没有继承的数据将保持绘制的状态。

### 5，裁剪图片节点

    （1）描述：根据输入的图片和ROI，裁剪图片。
    （2）参数：
        1）前一个节点输出的图片
        2）ROI节点的 输出矩形
    
### 6，面板图层节点

    （1）描述：绘制面板，并添加面板图层到右侧显示画布。本图层不会随图片的移动而移动。
    （2）参数：
        1）基底图像
        2）要显示的字符
        3）字符大小
        4）字符位置

### 7，文字图层节点

    (1)描述：绘制文字思维图层，该图层会随图片的移动而移动随着图片的缩放而缩放。
    (2)操作：双击节点，弹出配置面板，文字会被显示在该区域内，可以左键点击拖拽文字，右键点击拖拽画布。右侧的参数面板可以精确控制文字的属性，文字的位置被拖拽变化后，面板显示的属性也会同步更新。
    (3)参数：
        1）基底图像
        2）要显示的字符串

## 二、前处理文件夹

    前处理文件夹下存放的是图像处理节点，这些节点都是前处理节点，即输入图片，输出处理后的图片。

### 1，高斯模糊

    （1）描述：高斯模糊，一种平滑图片的方式，输入原图片，输出模糊处理后的图片。可用来消除图片中的噪声。
    （2）参数：
        1）输入图片
        2）高斯核大小

### 2，中值模糊

    （1）描述：中值模糊，一种平滑图片的方式，输入原图片，输出模糊处理后的图片。可用来消除图片中的噪声。
    （2）参数：
        1）输入图片
        2）核大小

### 3，二值化

        （1）描述：二值化，将图片转换成二值图片。大于阈值的像素点为255，小于阈值的像素点为0。是提取轮廓经常用到的前处理
        （2）参数：
        1）输入图片
        2）阈值

### 4，形态学运算

    （1）描述：形态学运算，对图片进行形态学处理，如腐蚀、膨胀、开、闭、梯度、礼帽、黑帽等。可以消除小的高光片、去除噪声、提取轮廓等。
    （2）参数：
    1）输入图片
    2）操作类型
    3）核大小

### 5，颜色空间转换

    （1）描述：颜色空间转换，将图片从一种颜色空间转换为另一种颜色空间。
    （2）参数：
    1）输入图片
    2）颜色空间转换类型（比如彩色转灰度，提取RGB通道）

### 6,边缘检测

    （1）描述：边缘检测，将图片的边缘提取出来。
    （2）参数：
    1）输入图片
    2）阈值1
    3）阈值2
    2）边缘检测类型
    3）L2距离

## 三，图像检测节点

    存放核心视觉检测节点，比如：特征匹配，找直线，OCR,区域查找等等；

### 1,特征匹配

    （1）描述：提取ROI的特征,进行特征匹配，一般做定位用，也可检测错漏装
    （2）参数：
        1）输入图片
        2）模板图片（要查找的物体）
        3）ROI
    （3）返回：
        1）是否匹配到：bool
        2）匹配结果中心：(x,y)
        3）匹配结果角度：弧度制
        4）匹配结果尺寸：宽和高

### 2,找直线

    （1）描述：找直线，一般做定位用，可以输出直线信息：线段起点、终点
    （2）参数：
        1）输入图片（边缘检测后的图片）
        2）ROI
        3）相关赛选阈值，如长度范围，角度范围，最小间隔

### 3,OCR识别

    （1）描述：OCR识别，一般做文字识别用，可以提取ROI内文字，并输出识别结果
    （2）参数：
        1）输入图片
        2）ROI

### 4,图像均值

    （1）描述：图像均值，可以输出均值结果，在一些简单的颜色检测中，配合颜色转换节点可以检测颜色是否在指定范围内
    （2）参数：
        1）输入图片
        2）ROI
    （3）输出：
        1）均值结果

### 5，逐像素比较

    （1）描述：逐像素比较，可以输出结果，在某些场景下，可以判断图片是否相同，找出不同的区域，配合blob节点可以找出图片中不同的区域，如找出图片中颜色不同的区域或者运动的区域
    （2）参数：
        1）输入图片
        2）参考图片
    （3）输出结果   
        3）输出结果为原尺寸的图片，结果为0的地方为相同，结果为255的地方为不同

### 6，区域查找

    （1）描述：配合二值化节点可以找出指定形状的区域，也可统计指定形状的区域数量
    （2）参数：
        1）输入图片
        2）查找的形状
        3）高度筛选
        4）宽度筛选
        5）面积筛选
    (3)结果：
        1）输出检测到的个数
