# 数学节点库

    描述：数学节点库，存放基本和常用的数学算子节点，同时也是其它节点库的依赖项，负责所有节点库的基础数据类型。

## 1，常量节点

    （1）描述：无输入。输出为指定类型和值的常量。
    （2）操作：单击该节点，右下侧的节点属性栏里的高级选项组合里出现可配置项，默认为bool量（开关量，信号量），可点击类型下拉框里的小箭头选择变量类型。
	（3）可选类型：
        1.）bool:布尔量,开关量，信号量
        2.) int:整数 
        3.) float：浮点数 
        4.) string :字符串
        5.) vect：数学中的向量
    （4）例如：
        点击：bool，输入：true 或者 false
        点击：int，输入：123
        点击：float:，输入：12.34
        点击：string,输入：abcd
        点击：vect,输入：1,2(注意逗号是英文的逗号
        点击：math.pi 此时输入会被覆盖，输出自动更改为3.1415926535.....，数据类型为double

## 2，列表节点

    （1）描述：列表节点，用于创建列表。像常量节点一样，也有类型可以选择，选择后创建包含指定类型的列表变量。
    （2）操作：单击列表节点，右下侧的节点属性栏里的高级选项组合里出现可配置项，默认为bool量（开关量，信号量），可点击类型里的小箭头选择变量类型。
    （3）可选类型：
        1.）bool:布尔量,开关量，信号量
        2.) int:整数 
        3.) float：浮点数 
        4.) string :字符串
        5.) vect：数学中的向量
    （4）例如：
        点击：bool，输入：true,false
        点击：int，输入：12,34
        点击：float:，输入：12.34,3.14
        点击：string,输入：ab,cd
        点击：vect,输入：[(1,2),(3,4)](注意逗号是英文的逗号)

## 3,随机数节点

    （1）描述：随机数节点，用于生成随机数。
    （2）操作：单击随机数节点，右下侧的节点属性栏里出现节点的配置框，输入输出的范围。
    （3）例如：输入：1,8 输出：1~8的随机数
    
## 4,数值过滤器节点

    （1）描述：数值过滤器节点，用于对输入的数值进行过滤。
    （2）操作：单击数值过滤器节点，右下侧的节点属性栏里出现节点的配置框，输入输出的数值范围。
    （3）参数：
        1）任意数（类型：float） 
    （4）输出：
        指定范围的数，不在范围的数被截掉。同时 是否 置false,在范围内的数原样输出，是否 置true。
    
## 3，逻辑门节点

    （1）描述：逻辑门节点是逻辑运算的节点，与门和或门的输入为两个或者两个以上的布尔值，输出为一个布尔值。非门的输入为布尔值，输出为非布尔值。
    （2）逻辑门节点有：
        1.) 与门
        2.) 或门
        3.) 非门
    （3）操作：双击逻辑门节点，弹出节点配置面板：可以选择逻辑门类型，默认为与门。也可以调节节点的输入引脚数量，与门和或门输入引脚数量为2，非门输入引脚数量只能为1。
    （4）例如：
        与门：输入：false,false,true->输出：false
        与门：输入：false,true,true->输出：false
        或门：输入：false,false,true->输出：true
        非门：输入：true->输出：false
